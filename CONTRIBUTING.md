# Contributing

Thanks for helping improve Car Service Voice Assistant.

## Ground Rules
- Be respectful and constructive
- Keep changes focused and easy to review
- Avoid committing secrets or credentials

## How To Contribute
1. Open an issue describing the change or bug
2. Fork and create a feature branch
3. Make changes with clear commits
4. Open a PR with a short summary and screenshots where relevant

## Development Notes
- Backend lives in `AgentServer/`
- UI lives in `AgentUi/agent@ui/`
- MCP tools live in `cars_mcp/`

## Tests
- Backend: add or update tests in `AgentServer/tests/`
- UI: add or update tests alongside components

## Code Style
- Python: prefer `black`-compatible formatting and type hints
- JS/TS: follow the existing ESLint configuration
